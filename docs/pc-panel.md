# 腕录电脑端：听悟工作台

本分支继续使用普通通义听悟账号，不要求百炼 API Key。电脑面板直接读取听悟任务、转写和纪要，也能把本地录音上传到同一账号。此接入沿用手表 2.2 的实验性官网兼容协议，不是开发者 OpenAPI。

## Windows 安装使用

在 GitHub Releases 下载 `WanLu-2.3.0-Windows-x64.exe`，按向导安装后双击桌面“腕录”。安装包包含运行环境与 ADB，不需要另装 Python、Node 或 Android SDK。也提供 ZIP 便携版，解压后运行“腕录.exe”。

适用 Windows 10 / 11 x64。首次点击连接账号，在官方窗口扫码。程序自动启动本地服务；退出程序时关闭自己的服务。录音、登录配置和任务记录保存在当前用户的应用数据目录，升级和卸载不会主动删除这些数据。安装包为项目自行构建，未配置商业代码签名。

启动仅显示一个工作台窗口；官方登录窗口只在点击登录按钮时显示，ADB 检查和录音拉取在后台运行。安装版数据目录是 `%APPDATA%\WanLu`，录音与任务记录位于其中的 `data` 子目录。

## 从源码启动

需要 Python 3.11+、Node.js 22.12+；手表连接需要 Android SDK platform-tools 中的 adb。

```powershell
python -m pip install -r pipeline/requirements.txt
npm install
npm run install:desktop
python pipeline/server.py
```

打开 <http://127.0.0.1:8733>，后续可双击 `pipeline/启动面板.bat`。

## 连接现有听悟账号

1. 在工作台点击“连接听悟账号”。
2. 在独立的通义听悟官方窗口，用与手表、手机相同的账号完成登录。二维码、账号密码与登录确认由用户在官方页面处理，面板没有凭据输入框。
3. 工作台出现“听悟账号已连接”后，自动显示该账号的云端记录。可搜索、翻页、查看处理状态。
4. 选择一条记录，在“会议纪要 / 转写原文 / 原始结果”间切换，支持复制、下载 Markdown 和刷新结果。

原有手表会话保留，电脑另行登录同一账号。源码版登录窗口使用独立浏览器配置，保存在被 Git 忽略的 `.local/tingwu-browser/`，安装版使用上述应用数据目录；仅电脑登录组件与本机服务之间交换会话。Cookie 不返回网页，也不进入任务日志或 Git。可用的官网持久会话会自动恢复；官网会话失效或未保留时，需要点击登录按钮重新登录，程序不会反复自动弹出登录窗口。

## 手表录音和上传

- “腕录 2.2（听悟版）”从应用私有录音目录读取文件，兼容旧版外部目录。电脑默认选择听悟预览版，原版仍可切换。
- 在“手表上的”勾选文件，点击“拉取到电脑”。这只复制录音，手表原件保留，不会上传到云端。录音进行中不能拉取。
- 也可“导入音频”到电脑，支持 m4a、mp3、wav 等格式，单个不超过 256 MB。相同内容重导入保留一份，同名不同内容不覆盖原件。
- 在“电脑本地”勾选录音，点击“上传听悟”，确认记录名称及账号额度使用后再提交。电脑上传直接使用听悟账号，未调用百炼转写或独立纪要模型。
- 左侧展示电脑上传状态，右侧展示真实云端处理状态。“已上传”只表示云端接受录音，不保证转写或纪要已经完成。云端任务约每 15 秒刷新，结果可主动刷新。

## 编辑、改名和回收站

选择记录后可改名，或按段编辑转写原文和纪要。修改会同步到听悟账号；编辑原文时保留段落起止时间。保存前重新核对云端版本，发生其他设备同时修改时返回冲突提示，保留编辑框内容供复制和重新核对。修改前的文本快照保存在私有的 `edit-history` 目录。

“移入回收站”需要页面中明确勾选确认，使用听悟的可恢复删除；不会永久删除云端内容，也不会删除电脑和手表原件。工作台提供回收站列表与恢复操作。

## 取消和恢复上传

排队和上传中均可取消，上传进度按 64 KiB 分块更新。取消会关闭当前传输连接；如果正在建立或确认云端记录，需要等当前请求返回后才能确定最终状态。已被听悟接受的录音通过右侧云端记录管理。

## 恢复与账号隔离

电脑上传任务按听悟账号与音频 SHA-256 去重，保存在 `.local/tingwu-jobs.json`。重启将未完成任务标为“已中断”，需要用户点击恢复。

已有云端记录时先查询同一条记录，不盲目创建副本。创建请求超时且尚未拿到记录 ID 时，保存原任务 UUID，可用“核对云端记录”查询同一条记录，禁止盲目重建。文件变化或账号切换时暂停原任务。上传地址过期且不能继续时，可将对应云端记录移入回收站，确认回收站记录仍在后重新上传。恢复旧记录会同步撤销重新创建资格，避免制造副本。成功后清除任务缓存中的临时存储链接。

仅本机可调用听悟账号接口；服务保留旧版手表局域网推送，因此不要将 8733 映射到公网。任务与私有结果不是公开共享页面。

## 保留的旧版工具

`/legacy` 提供原有百炼面板，仅供主动选用旧开发者方案时使用。本轮修复了旧流程的会议主题参数、Paraformer 结果解析、任务参数隔离和仅重试纪要；它不参与默认听悟流程。

## 构建 Windows 发布包

开发环境需要 Python 3.14、Node.js、Android platform-tools。运行 `npm run build:windows`，生成 `dist-desktop` 中的安装包、便携 ZIP 和 SHA-256 清单。构建仅包含明确列出的代码与资源，排除录音、Cookie、私有配置和用户任务文件。

手表继续使用现有 2.2 APK，本轮 Android 功能代码未改动，不需要为电脑端升级而卸载手表应用。发布附件保留与现有设备相同签名的 2.2 安装包。
