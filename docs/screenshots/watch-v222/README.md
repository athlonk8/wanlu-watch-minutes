# 手表 2.2.2 布局图

这些 PNG 来自生产界面的 Jetpack Compose 代码，经 Robolectric 原生 Android Canvas 渲染，视口 466 × 466、320 dpi、圆屏布局。截图用于审阅按钮外观、中文排版及圆屏空间，不是本轮 OWW261 的实机截图。

- `idle.png`：开始录音大按钮。
- `recording-demo.png`：录音状态示意，计时为合成状态，未启动录音服务或麦克风。
- `files.png`：一条 1 秒合成静音 AAC 文件的操作卡片，未上传；日期仅为界面样本。
- `tingwu.png`：未连接账号时的官方扫码入口，未展示二维码、登录凭据或用户会议。

主按钮在此尺寸下为约 168 × 78 dp（较小屏幕按比例收缩），主要操作按钮至少高 52 dp。高光限制在按钮轮廓内，按下时按钮面下沉；文件与传输页为底部页码保留独立空间。录音中的文件管理限制、删除二次确认、已有上传任务取消入口保留。

构建、34 项既有单元测试和 `lintDebug` 已完成验证；这些图不作为新增真实录音、云端识别质量或真机安装验收的证据。此前的真机直传验证见 [2.2 验证记录](../../tingwu-direct-status.md)。
