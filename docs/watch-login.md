# 手表听悟扫码登录（2.2.3）

1. 打开绿色麦克风图标的“腕录”，左滑到“听悟直传”。
2. 点“支付宝扫码登录”，用手机支付宝扫描手表上的官方二维码，并在手机确认。
3. 成功后手表自动返回直传页，显示“听悟账号已连接”。如需录音结束即上传，可自行开启“结束后自动上传”。

如果系统充电画面遮住应用，可在保持连接的情况下按手表侧键退出该画面。二维码过期时点底部“登录”刷新；“检查登录”只核对账号状态。

## 本次修复

听悟首页能够加载，但其内嵌登录组件有时显示“网络出现问题”。旧版本未自动转到页面提供的备用登录入口，备用网页的二维码也超出了手表视口。

2.2.3 检测这条错误提示后，只接受网页提供的 `https://account.aliyun.com/login/login.htm` 官方地址，并保留原有回调参数；切换后调整现有二维码容器的位置与尺寸，不重绘二维码或替换认证流程。主页面加载失败时显示明确提示，由“登录”按钮重试，避免持续自动重载。

会话由手表 WebView 保留，不要求百炼 Key。二维码、Cookie 和回调票据不进入 Git、发布包或诊断日志。
