# 手表音质档位（2.2.4）

在录音首页点底部“音质…调整”，点选档位后返回首页并保存选择。退出再打开会读取已保存的选项；没有保存过档位的安装默认使用 96 kbps。

| 档位 | 目标码率 | 每小时约占 |
| --- | --- | --- |
| 标准 | 64 kbps | 29 MB |
| 高清（默认） | 96 kbps | 43 MB |
| 更高 | 128 kbps | 58 MB |

文件体积是按目标码率估算的近似值，封装和设备编码器可能带来差异。保持麦克风音源、44.1 kHz、单声道、AAC 编码与 M4A 容器；更高码率减少压缩损失，不保证语音识别更准确。

档位仅影响之后的新录音，既有文件不重新编码。录音服务开始时读取一次配置并锁定本段参数；录音期间入口不可调整，首页显示本段码率。设置内容无效或类型不匹配时使用 96 kbps。
