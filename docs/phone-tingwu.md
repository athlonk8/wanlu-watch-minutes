# 使用现有通义听悟账号

> 这是备用传输指南。2.2 默认使用手表直接上传听悟，见 [直传验证记录](tingwu-direct-status.md)。蓝牙发送到手机后手动导入仅作备用。

备用路径是：**手表录音 → 蓝牙发送到已配对手机 → 手机手动导入通义听悟 → 在听悟查看转写与纪要**。不需要自行购买 OSS、函数计算或配置百炼 Key，也不需要安装新的手机 App。

## 一加手机操作

1. 保持一加 ACE6 与手表原有的蓝牙配对和共享网络连接。无需为上网另开热点。
2. 手表腕录左滑进入录音列表，点开一段录音，选择“蓝牙发到手机”。
3. 在第三页选择已配对的手机，保持手机蓝牙开启；手机出现蓝牙文件接收请求时确认接收。
4. 在手机的文件管理器或蓝牙接收记录中找到 `.m4a`，然后在你日常使用的听悟网页／App 中选择本地音视频导入。不同版本的听悟入口可能不同，以实际界面为准。
5. 转写、发言人区分和纪要均在听悟中查看。腕录不会把普通账号当作开发 API，也不会读取听悟登录凭据或自动提交转写任务。听悟自身的额度与计费规则适用。

蓝牙发送采用标准 OPP / OBEX 文件传输。是否最终可用取决于手机是否开放蓝牙文件接收及其确认提示；共享手机网络连通不等于文件接收能力已开启。发送失败时原录音保留，应用不会通过电脑中转。

## 同一 Wi-Fi 下的备用传输

选择录音后，第三页有“同 Wi-Fi 扫码（备用）”。这会在手表上为**选中的一段录音**开启 15 分钟临时传输页：

1. 手机和手表连接同一可信 Wi-Fi；也可让手表连接手机热点。
2. 手机扫码，或在浏览器输入手表显示的地址，再输入六位配对码。
3. 点“下载录音到手机”，确认浏览器下载完成，再到听悟手动导入。
4. 完成后点手表“结束传输”；超时也会自动关闭。

临时页支持断点下载，不提供文件删除或上传接口；下载不会删除手表原件。二维码凭据放在 URL 片段中，页面打开后会清除片段并使用短期 HttpOnly Cookie。此传输仅用于自己的热点或可信局域网，不是公网服务。

**蓝牙共享网络的代理地址／VPN 地址不能当作局域网传输地址。** 2.1 只从真实 Wi-Fi／以太网网络获取备用传输地址，不会把蓝牙代理或 `tun0` 虚拟网卡地址显示成手机可访问的地址。只有蓝牙借网时，备用二维码页会提示连接 Wi-Fi；这不表示手表无法上网。

## 开发验证

```powershell
cd watchrec_app
.\gradlew.bat -PwanluPreview=true :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
```

蓝牙单元测试验证 OBEX 协商、分包、文件字节、最后确认、接收拒绝和取消；局域网测试验证鉴权、配对码尝试次数、Host/Origin、范围下载、会话过期和文件保护。真实手机接收与听悟导入需要手机端确认，不能仅凭单元测试宣称完成。

2026-10-23 在这块 OWW261 手表观察到：默认网络为 `COMPANION_PROXY`，传输类型 `BLUETOOTH`，状态 `CONNECTED`，能力含 `INTERNET` 与 `VALIDATED`；通过此网络访问 `https://tingwu.aliyun.com/` 返回 HTTP 200。没有据 Wi-Fi 网卡缺少地址判定手表离线。
