# WanLu watch launcher icon

The circular evergreen microphone icon was created with the built-in image generation tool on 2026-10-26. The transparent PNG is the project master. Run `python scripts/create-watch-icons.py` with Pillow installed to export Android launcher densities and the adaptive-icon resource. Exports only resize the supplied artwork.

Final generation prompt:

> Use case: logo-brand. Asset type: production launcher icon for WanLu, a wristwatch voice recording app. Create one beautiful, highly recognizable circular app icon, square 1024x1024 canvas, transparent outside the perfect circular badge. Existing app has a mint-green recording interface, so use deep evergreen/teal for the circular badge, a luminous warm-white large sculpted microphone as the unmistakable central symbol, and a small vivid coral recording dot integrated neatly near its upper right. A single elegant mint sound-wave arc on each side of the microphone, broad and simple. Premium restrained soft 3D enamel treatment with subtle depth and tasteful lighting, very crisp silhouette and strong contrast, readable when reduced to 40 pixels on a round watch launcher. The perfect circle fills 96 percent of the canvas and is centered; keep all microphone and dot details inside the central 65 percent of the canvas for Android adaptive icon safe area. Face-on symmetrical composition, no perspective. No text, no letters, no watermark, no mockup, no extra outer ring, no tiny decoration, no background outside the circular badge. Deliver the finished icon artwork only, not a presentation sheet.
